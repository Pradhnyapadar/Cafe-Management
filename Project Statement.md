Project Statement

This Python project is a simple Café Billing System that allows users to
view a menu, place orders, calculate the total bill, and print a
formatted receipt. The menu is stored as a dictionary, and the program
interactively takes user inputs for items and quantities. It computes
the cost for each item, maintains an order list, and displays the final
bill with all ordered items and their totals. This project demonstrates
the use of functions, loops, dictionaries, and basic input handling in
Python.
